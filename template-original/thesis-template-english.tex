\fbox{\parbox{0.98\linewidth}{
This template contains exemplary (and thus incomplete) structural elements, components and guidelines for a typical software development project where a prototype is created. It serves as assistance for your further use. 

Of course, you must make additional supplements and adaptations yourself.

\begin{center}
\textbf{Good luck and success with your thesis!}
\end{center}
}}

The main text begins here and is numbered in Arabic numerals starting with "1" on this page. The main text is divided into chapters and subchapters. If each hierarchical level should be named, the following terminology is common:

\begin{itemize}
\item 1st hierarchical level: Main chapter
\item 2nd hierarchical level: Chapter  
\item 3rd hierarchical level: Subchapter
\item 4th hierarchical level: Section
\end{itemize}

The content structure of a thesis in the \textit{International Media and Computing} program naturally depends on the topic and content. Deviations from the structural framework underlying this template are always possible, sometimes even absolutely necessary. Always coordinate with your supervisors in this regard.

Never forget to cite all your sources correctly\footnote{For additional information on citation, you can refer to supplementary sources (e.g. \cite{balzert2011}).}. Sources can be manually referenced and entered in the bibliography. Additionally, many text processing systems also offer external source management files and systems through which citations can be made in the main text using appropriate commands.

Visualize appropriately in the main text, e.g., using figures and tables. This template contains exemplary integrated figures and a table for illustration purposes.

\section{Tips for Writing Your Thesis}

\begin{itemize}
\item Use neutral, professional language. Avoid first person ("I").
\item Cite credible and worthy sources (e.g., scientific articles and textbooks; avoid blogs and never cite Wikipedia\footnote{Wikipedia itself recommends avoiding citation of Wikipedia content in academic contexts.}).
\item Cite correctly and consistently.
\item Do not use footnotes for literature references.
\item Research thoroughly the state of science and technology.
\item Pay attention to the quality of the work (e.g., spelling).
\item Inform yourself in advance about how to work and write scientifically.
\item Use \LaTeX\footnote{No support provided for installation, use and adaptation of \LaTeX templates!}.
\end{itemize}
