\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
% English abstract
When faced with the challenge of creating content and interactive web experiences, less technical users have to rely on tools like \gls{CMS} like WordPress and \gls{WYSIWYG} editors.

Although these tools partially satisfy the needs of modern web experiences, many of them have their shortcomings when it comes to the \gls{staticweb} they produce, as well as a certain level of inaccuracy between the preview layer and the final rendered content in the Web browser.

Due to the static output of tools like Webflow, WordPress, Wix, etc., users cannot make use of the \gls{SPA} features that come with modern JavaScript frameworks like React, NextJS or VueJS.

The following thesis answers the question of how a multilayered visual application builder allowing real-time UI editing, dynamic CSS class generation, and multi-touch interactions can be implemented using the modern JavaScript framework NextJS. Lowering the barrier of entry to build great software by applying the concepts of meta-programming.

"Meta-programs analyze, generate, and transform object programs. In this process, object programs are structured data."\cite[p.~299]{visser2002}

\section{Tips for Writing Your Thesis}

\begin{itemize}
\item Use neutral, professional language. Avoid first person ("I").
\item Cite credible and worthy sources (e.g., scientific articles and textbooks; avoid blogs and never cite Wikipedia\footnote{Wikipedia itself recommends avoiding citation of Wikipedia content in academic contexts.}).
\item Cite correctly and consistently.
\item Do not use footnotes for literature references.
\item Research thoroughly the state of science and technology.
\item Pay attention to the quality of the work (e.g., spelling).
\item Inform yourself in advance about how to work and write scientifically.
